# M₀: детерминированная семантика состояния

[English](../README.md) · **Русский** · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Português](README.pt-BR.md)

M₀ — небольшая формальная модель *состояния, которое остаётся частью протокола, в то время
как расписание — нет*. Она нацелена на системы, где повторное воспроизведение прогона обязано
дать байт-в-байт идентичный наблюдаемый вывод: реплицируемые машины состояний,
детерминированные симуляции, матчинг-движки, ядра баз данных.

Изучаемое свойство, неформально:

> если два расписания семантически эквивалентны для одного журнала, наблюдаемый вывод прогона
> идентичен

Формально `schedule₁ ≈_J schedule₂ ⇒ Observable(run₁) = Observable(run₂)`, с эталоном
`Seq(P, J) = fold(J)`.

Модель: транзакционные ячейки, оптимистичное исполнение по снапшоту, валидация снапшота на
коммите, коммит строго в порядке журнала.

## Что доказано

| Слой | Содержание | Статус |
| --- | --- | --- |
| L1 | детерминированный последовательный fold | доказано |
| L2 | упорядоченный коммит + валидация ⇒ Parallel = Seq | доказано |
| L3A / L3B | граница допустимых расширений + контрпример `scheduleCounter` | доказано |
| L3.5 | semantic ⊊ observable ⊊ coincidence | доказано |
| L4 | независимость от субстрата (`SoundSubstrate`) | доказано |
| L5 | устойчивость к отказам: закон `forced` ослаблен до префикса журнала (`FailSoundSubstrate`), crash-stop машина как инстанс | доказано, релиз v1.1 |

Механизация: Lean 4.31.0, `0 sorry`, из аксиом только `propext` и `Quot.sound`; главная
теорема `substrate_independence` не использует ни одной. Помимо доказательств есть враждебный
дифференциальный свидетель `witness/m0.py` с негативными субстратами и гейтом покрытия.

## Быстрый старт

Lean 4.31.0 (ставится автоматически через `elan` из `lean-toolchain`) и Python 3.10+.

```bash
lake build                 # собрать все шесть Lean-файлов
python scripts/verify.py   # сборка + 0 sorry + след аксиом + свидетель
```

`scripts/verify.py` — та же команда, что гоняет CI; `PASS` печатается только если сборка
чистая, ни один файл не содержит `sorry`, след аксиом каждой теоремы совпадает с
задокументированным, а свидетель сообщает `ALL CHECKS PASSED`.

## Ограничения

Стоимостная семантика, liveness и промышленная реализация в артефакт не входят: M₀ — история
про safety. Свидетель — средство фальсификации, а не второе доказательство.

Полная документация, структура репозитория и детали свидетеля — в
[английском README](../README.md).
